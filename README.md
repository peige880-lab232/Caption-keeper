# Caption Keeper

一個本機 Windows 小工具，用來記錄 Microsoft Teams 顯示中的「即時輔助字幕」。它不會操作 Teams、不會自行開啟轉錄，也不會在背景錄音。你手動開啟 Teams 的即時字幕、框選字幕面板、按開始後，它會：

- 每 1–10 秒擷取一次你選定的字幕區域；
- 以本機 OCR 擷取中英文字幕，並盡量排除畫面捲動造成的重複內容；
- 將含「姓名＋發言內容」的紀錄保存在 `文件\CaptionKeeper` 的 Markdown 和 JSON 檔。

## 安裝（一次）

1. 安裝 [Python 3.12（64-bit）](https://www.python.org/downloads/windows/)。目前的本機 OCR 套件相容於 Python 3.12；安裝畫面務必勾選 **Add Python to PATH**。
2. 開啟 PowerShell，切換到此資料夾後執行：

   ```powershell
   py -m pip install -r requirements.txt
   ```

## 啟動

直接雙擊 `開啟 Caption Keeper.vbs`（建議，不會顯示黑色命令視窗），或在 PowerShell 執行：

```powershell
py caption_keeper.py
```

使用順序：

1. 在 Teams 會議中自行開啟「即時輔助字幕」。
2. 點 `1. 選取字幕區域`，框住頭像、姓名與字幕所在的完整區域。字幕面板之後不可移動、最小化或被遮住。
3. 「略過頭像左欄（px）」預設 `52`，會裁去最左側頭像，保留右側的姓名與字幕。若仍有頭像被誤判為文字，增加 10px；若姓名消失，減少 10px。調好一次後，同一 Teams 版面可沿用。
4. 點 `2. 開始記錄`。錄製檔案會即時寫入 `文件\CaptionKeeper`。
5. 需要查看檔案時，按「開啟最新紀錄資料夾」即可直接開啟 `文件\CaptionKeeper`。
6. 會後按「停止記錄」。工具不會將內容上傳至任何服務。

## 辨識品質（改良版）

- 擷取影像會放大三倍，再作自動對比與輕度銳化，讓 Teams 的小字更容易辨識。
- 低信心或明顯非文字的結果（常見於頭像、按鈕與圖示）不會寫進紀錄；建議框選時只保留姓名和字幕，排除表情符號、工具列與參與者頭像。
- 程式會辨識像 `ScottGraybeal` 這種被合併的已知說話者名稱，並用它來切開捲動畫面中的重疊字幕；少數英文常見連字也會保守地補上空格。
- 若人物名稱漏掉，請將「略過頭像左欄」每次減少 10px；若仍出現雜訊，增加 10px。字幕字體放大一級通常比縮短擷取頻率更能提升正確率。

## 注意

- OCR 會保留字幕面板中可辨識的說話者姓名，但仍可能漏字或合併字幕。會後請快速核對決策、姓名與日期。
- 這不等同 Teams 原生的會議逐字稿；若能取得原生 `.docx`，應以原生檔為準。
- 開會前請遵守公司資訊安全、錄音與隱私規範，並在需要時取得主辦人／與會者同意。
